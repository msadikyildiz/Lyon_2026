# Figure coverage

`reproduce.py` produces every numbered figure. All numerical panels are rendered from included inputs; schematics retain supplied artwork. The default uses validated dose-response fits and computed single-cell results. `--refit` rebuilds the dose-response fits in an isolated copy; `--single-cell` reruns the count-matrix analysis with the locked R environment.

Ten assemblies contain 50 numerical placements generated at their final panel sizes. `assembly_layout.json`, `out/print-panels/manifest.json` and `assembly_manifest.json` record the geometry and source hashes. Additional genomic, single-cell and schematic assemblies are generated by scripts in `scripts/`; their crosswalks, validation records and assembly manifest are included.

Source Data contain per-figure values and provenance. Supplementary Tables 1/2 retain manuscript source values. Table 3 contains complete single-cell sample/cluster results; Table 4 contains culture comparisons, enrichment results and targeted marker checks. Enrichment result worksheets are supplied inputs, checked against original EcoCyc exports where available. Table 4 includes the full 133-row parent-up export. Enrichment results are inputs; the repository validates and exports them without rerunning EcoCyc tests.
