# Input provenance

The original dose-response and plate-layout workbooks are in `working/analysis/stats-rework/biohpc-pull/data`. Their original trailing OD column is preserved because the notebook preprocessing removes that column explicitly. The six fitted caches retain the culture IDs, fit grids, bootstrap draws and dose-level records used in the analysis. plategig source is vendored at commit `88839a2`; its MIT license is included.

Growth, survival and MDK workbooks are retained under their figure directories. The original manuscript tables were exported to `data/supplementary_tables.json`; no manuscript DOCX is needed to regenerate Source Data. Panel artwork extractions remain in `data/figure-assets` with their hashes and identities. All numerical panels are generated from data. Figure 4d uses the vector PDF exported from the original BioRender project. Its source slide, crop coordinates and citation are recorded in `Figure4_schematic.json`. Credit: Created in BioRender. Toprak, E. (2026) https://BioRender.com/lgurs80. Supplied schematic artwork is identified separately by `schematic_sources.json` and `Figure4_schematic.json` in that directory.

Genomic metadata, all 149 per-sample mutation-call TSVs, 17 supplied processed exports and regenerated tables are described in `data/genomics/README.md`. Notebooks use portable paths and a repository-root bootstrap. Five survival notebooks use the bundled DejaVu Sans font. Reference sequences, command lines and saved options for all 149 runs are included under `data/genomics`, with mappings in `run_records`. The genomic README records version assumptions based on the latest release before each run date. Whole-genome sequencing data were submitted under NCBI BioProject [PRJNA1534522](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1534522).

Single-cell count matrices, original Rmd code, GEO metadata templates and final result tables are included in `data/single-cell`. Its README records sample identities, reconstruction methods and table mapping. The 31 selected source files retain their original bytes, with archive paths and duplicate checks in `input_manifest.json`. Five EcoCyc text exports retain original bytes under `data/single-cell/enrichment/exports`. Four have matching workbook worksheets; the fifth is an additional comparison. The [enrichment record](../data/single-cell/enrichment/README.md) explains coverage and the complete parent-up export. The documented EcoCyc workflow uses Fisher’s exact test and Benjamini–Hochberg correction; EcoCyc 29.0 and default annotation-specific backgrounds are assumed as documented in the enrichment record.

`data/INPUT_SHA256SUMS` records the supplied data, reference notebooks, cache files, vendored source, schematic assets, R dependency lock and all four input manifests. Verify from the repository root with `shasum -a 256 -c data/INPUT_SHA256SUMS`. `data/genomics/input_manifest.json` records the individual checksums of all 166 supplied genomic files, which `scripts/reproduce_genomics.py` verifies before and after execution. `scripts/reproduce_single_cell.py` checks all 31 selected single-cell inputs against their manifest. `data/genomics/run_records/manifest.json` additionally maps all 600 entries in the reference/run-record archive to 453 distinct retained files. `scripts/verify_breseq_records.py` checks all 149 run identities, commands, summaries and reference sequence matches. `scripts/verify_enrichment.py` checks the five original EcoCyc exports and their matching worksheet results. Generated results and runtime logs are excluded from the input checksum list.
