# Input provenance

The original dose-response and plate-layout workbooks are in `working/analysis/stats-rework/biohpc-pull/data`. Their original trailing OD column is preserved because the historical preprocessing removes that column explicitly. The six fitted caches retain the culture IDs, fit grids, bootstrap draws and dose-level records used in the analysis. plategig source is vendored at commit `88839a2`; its MIT license is included.

Growth, survival and MDK workbooks are retained under their figure directories. The original manuscript tables were exported to `data/supplementary_tables.json`; no manuscript DOCX is needed to regenerate Source Data. Historical panel extractions remain in `data/figure-assets` with their hashes and identities. All numerical panels now regenerate from data. Supplied schematic artwork is identified separately by `schematic_sources.json` and `Figure4_schematic.json` in that directory.

Genomic metadata, all 149 per-sample mutation-call TSVs, 17 supplied processed exports and regenerated tables are described in `data/genomics/README.md`. Notebook outputs and execution metadata were cleared; scientific code is retained with portable paths and a repository-root bootstrap. Five survival notebooks select the bundled DejaVu Sans font explicitly, matching the original Nimbus Roman fallback on the validation machine. Upstream reference-genome/caller records and sequencing-read accessions remain to be added.

Single-cell count matrices, original Rmd code, GEO metadata templates and final result tables are included in `data/single-cell`. Its README records sample identities, reconstruction methods and table mapping. The 31 selected source files retain their original bytes, with archive paths and duplicate checks in `input_manifest.json`. Enrichment calculation settings, database version and tested background remain needed; full enrichment results and gene memberships are included.

`data/INPUT_SHA256SUMS` records the supplied data, reference notebooks, cache files, vendored source, schematic assets, R dependency lock and both input manifests. Verify from the repository root with `shasum -a 256 -c data/INPUT_SHA256SUMS`. `data/genomics/input_manifest.json` records the individual checksums of all 166 supplied genomic files, which `scripts/reproduce_genomics.py` verifies before and after execution. `scripts/reproduce_single_cell.py` checks all 31 selected single-cell inputs against their manifest. Generated results and runtime logs are excluded from the input checksum list.
